Hp T630另一用途——打印服务器，支持苹果等无线打印。建立在Ubantu24平台上（CUPS Web打印、Portainer、VirtualHere等）一键部署脚本
# 多打印服务器

基于 HP T630 瘦客户机搭建的多接口打印服务器，支持苹果 AirPrint 无线打印、CUPS 打印管理、Web 网页文件直印及 USB 设备网络共享。

## 🚀 一键安装脚本 (Ubuntu 24.04 LTS)

在 Ubuntu 终端中执行以下命令，即可一键自动完成 Docker 环境搭建及全套服务部署：

curl -fsSL https://raw.githubusercontent.com/luomagogo/%E5%A4%9A%E6%89%93%E5%8D%B0%E6%9C%8D%E5%8A%A1%E5%99%A0/main/deploy.sh | bash
